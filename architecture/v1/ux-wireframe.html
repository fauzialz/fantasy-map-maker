Where every tool lives before we build it

A layout & interaction blueprint for the fantasy map editor. The numbered pins key each region to a locked design decision — references point at 03-architecture-decisions.md. This is structure, not final art.

Historical as of WP-32. This shows the single-toolbar shell the editor was built with. The chrome has since become two rows — a menu bar (Map · Edit · View · Help, the map title, save state, Generate, Export) above the tool row — the bottom autosave strip was absorbed into it, and the right rail dropped from five sections to two (Layers and Appearance): Generate moved into its own dialog with WP-23, and Map settings, Map and Canvas left with WP-32 and WP-30. The current layout is 11-editor-shell.md §4; the pins below are still accurate about why each region exists, which is what this document is for.

Annotations

Each pin marks where a locked interaction decision shows up in the UI.

  • 1

    Fixed semantic layers

    Six known layers in a fixed render order — no freeform Photoshop layers. Each toggles visibility & lock; you reorder objects within a layer.

    ADR-15
  • 2

    Contextual eraser

    “Erase” removes whatever the active tool makes — land geometry on Terrain (sea brush), discrete objects on Mountains/Forests/Icons.

    ADR-18
  • 3

    Rings are derived + toggleable

    Coastal rings are never stored — recomputed from the union of all land, clipped to water. Toggling is instant; count/gap are settings.

    ADR-13
  • 4

    Marquee multi-select

    Drag or shift-click to grab a whole range at once; transform or delete as one. Backed by a spatial index to stay fast at 1–2k objects.

    ADR-16
  • 5

    Generate replaces the canvas

    Noise generator fills terrain + mountains + forests. When the canvas isn’t empty it asks first, and the whole replace is one undo step.

    ADR-21 · 22
  • 6

    No login wall

    Sign-in is optional and only adds cloud save. The full editor, local autosave, and image export all work logged-out.

    ADR-07
  • 7

    Coast-detail slider

    Lives in the contextual Tool Options rail; drives coastline smoothing + simplification from stylized to natural.

    ADR-12
  • 8

    Bounded canvas + live status

    Preset size, clamped zoom (no infinite pan). The status bar shows zoom, cursor coords, and object count against the perf budget.

    ADR-20
